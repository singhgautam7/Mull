# Mull app size

Method: `flutter build appbundle --release [--obfuscate --split-debug-info=build/symbols] --target-platform android-arm64`, then `bundletool build-apks` (debug keystore) and `bundletool get-size total --device-spec arm64.json` (arm64-v8a, SDK 34, 420 dpi, en-GB). That is the per-device download Play serves an arm64 phone. Breakdown from `--analyze-size` (which cannot be combined with `--split-debug-info`, so it was run on an unobfuscated build).

## Notes

- R8: Flutter's release build already minified and shrank; the explicit flags change nothing in the output. No keep rules of our own: `jni` and `jni_flutter` ship consumer rules and the manifest classes are kept by AGP. AGP 9 rejects `proguard-android.txt`, so `proguard-android-optimize.txt` is used. Not run on a device here (emulator was off limits): run the release APK once before shipping.
- Obfuscation: Mull has no crash upload, so `build/symbols` is only for `flutter symbolize` by hand; keep it per release. Flutter warns the ELF still carries unobfuscated DWARF unless `--strip` is passed; not changed.
- Fonts: nothing fetches fonts (no `google_fonts`, no `http` in pubspec or lock). The italic variable font (202 KB) IS used (`FontStyle.italic` in word_card, search_screen, quiz_screen, info_screens), so it stays. Both are variable; subsetting would save more but needs a font change decision.
- Dependencies: every other direct dependency is imported in `lib/` or `test/`.
- pdf: 137 KB AOT plus bidi about 216 KB, roughly 350 KB uncompressed, about 120 to 140 KB of download (0.3 %). It is used once, for the printed shelf sheet. Replacing it is not worth it on size; revisit only if the PDF export is dropped.
- Native libs: `abiFilters` do not change an AAB download (Play serves only arm64 to an arm64 phone). `useLegacyPackaging = true` stores libs compressed, which is the smallest download (-74.5 KB here). The trade-off is that they are extracted at install, so installed size grows by roughly the uncompressed native code (about 9 MB), small against the 95.5 MB dictionary.
- Images: only the two widget previews were worth converting; lossless, so pixel identical. Splash PNGs (about 26 KB each, generated by flutter_native_splash) were left alone.
