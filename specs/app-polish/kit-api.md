# Motion kit API (for implementation agents)

Import `package:mull/core/motion/motion.dart` (or relative). Read the dartdoc in `lib/core/motion/*.dart` before using a primitive. Ported from Kuber v7.0.0 `lib/core/motion/`, values unchanged.

- **Level:** `Motion.levelOf(context)` returns `MotionLevel.expressive | subtle | off`. `Motion.reduced(context)` = not Expressive (old callers). `Motion.of(context, d)` / `Motion.curveOf(context, c)` keep working (short fade below Expressive). The level comes from `MullMotionScope` in `lib/app.dart` (setting + device class; phone's Remove animations or accessibility navigation forces Off).
- **Settings** (`lib/features/settings/settings_controller.dart`, `settingsProvider`): `motionPreference` (`MotionPreference.auto|expressive|subtle|off`, key `motion.preference`), `deviceClass` (`motion.deviceClass`), `motionLevel` getter, `floatingHeader` (bool, `header.floating`, default true), `pillMode` (`PillMode.always|scrollUp|scrollStop`, `header.pill`), `expressiveColors` (bool, `theme.expressive`, default true), `haptics` (bool, existing key `linger.haptics`, default true). Setters: `setMotionPreference`, `setFloatingHeader`, `setPillMode`, `setExpressiveColors`, `setHaptics`. Watch a single field with `ref.watch(settingsProvider.select((s) => s.field))`.
- **Tokens** (`Motion`, `lib/core/theme/tokens.dart`): springs `springFast` (800, 0.6), `springDefault` (380, 0.8), `springSlow` (200, 0.8), `springStandard` (700, 0.9), `springSubtle` (600, 1.0); cached curves `fastCurve`, `defaultCurve`, `slowCurve`, `standardCurve`, `subtleCurve` (each has `.settle` Duration and `.clamped`); `Motion.spatial(level, spring)` / `Motion.spatialCurve(level, curve)` pick the subtle spring at Subtle; effects `fxInstant` 90, `fxFast` 150, `fxDefault` 200 ms on `curveEffects` (never springs for opacity or colour); `staggerDelay(i)` (30 ms, max 6); `reflow` 230, `containerTransform` 240, `sheet` 260, `snackEnter` 180, `snackExit` 140, `digitRoll` 300; press `pressScaleCard` .98, `pressScaleSubtle` .99, `pressScaleFab` .96, `pressScaleChip` .96, `buttonGroupWiden` .15; header pill `pillAt` 32, `headerAt` 8, `pillHideAfter` 16, `pillShowAfter` 8, `pillStopDelay` 300 ms; `Motion.weightStyle(style, wght)`. Existing Perch values (`instant`, `fast`, `navIndicator`, `lensSwap`, `spring` easeOutBack, `decelerate` easeOutCubic...) are unchanged.
- **Springs on controllers:** `controller.springTo(target, spring)` (extension in spring_curve.dart; retargets from current value and velocity; use `AnimationController.unbounded`).
- **Pressable**`({child | builder(ctx, radius, pressed), onTap, onLongPress, kind: PressKind.card|row|button|iconButton|fab|chip, restRadius, pressedRadius, morphCorners, enabled})`. Listener based: wrap OUTSIDE an existing InkWell / GestureDetector; pass `onTap` only if there is no inner handler. Buttons, icon buttons, fab and chips morph corners at Expressive (circle to squircle: icon button rest = half its size, pressed 12). `onLongPress` fires `MullHaptics.longPress()`.
- **Lists:** `MotionListItem({child, present, animateIn, onRemoved})` (insert: fade + scale from .92 + height; remove: set `present: false`, drop the row in `onRemoved`). First-load stagger: use `Motion.staggerDelay(i)` for at most 6 items, never while scrolling. Keep lists lazy.
- **Expand / collapse:** `ExpandCollapse({expanded, child})`, `ChevronTurn({expanded, openDegrees})`.
- **Container transform:** `ContainerTransformRoute`, `containerTransformPage(...)` (GoRouter), `globalRectOf(GlobalKey)`.
- **Loading:** `ShapeLoader({size = 48, contained, color})` (shape-morphing indicator; Mull has no circular spinners today), `SkeletonCrossFade({loading, placeholder, child, shrinkOut})`, `ShimmerBox` (shared skeleton shimmer, one clock).
- **Text weight:** `AnimatedWeight(text, isActive:, rest:, active:, style:)`. Instrument Sans is variable; weights move the `wght` axis (`MullType`, `.weight(n)`).
- **Haptics:** `MullHaptics.tick()` (selection: switch, chip, segmented, tab, nav), `.longPress()`, `.threshold()` (drag crossed its commit point), `.confirm()` (save, success), `.reject()`. Throttled 50 ms, silent while scrolling, gated by the Haptics switch. Never call `HapticFeedback` directly.
- **Theme ripple:** `ThemeRipple.of(context).run(globalTapPosition, () => applyChange())` (the app is wrapped once in `app.dart`).
- **Sheets / dialogs:** `sheetStyle(context)` / `dialogStyle(context)` (route_styles.dart) give the `sheetAnimationStyle` / `animationStyle` for the current level. `showAppBottomSheet` (W1) applies it centrally; feature code does not add its own.

Rules for every change: animate only transform, opacity, clip and shape; RepaintBoundary where it helps; interruptible; never block input; no ticker at rest; tokens only (no raw durations, curves, colours or radii outside `lib/core/theme/`); no em dashes in strings; 48 dp minimum touch targets; TalkBack label and role on every new control.
